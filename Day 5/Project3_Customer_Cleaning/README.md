# Project 3: Customer Data Cleaning using Pandas

## Objective
Clean and validate customer records using Python and Pandas.

## Tools Used
- Python
- Pandas
- Jupyter Notebook
- Visual Studio Code

## Tasks Performed
1. Loaded customer data from a CSV file.
2. Inspected missing values and data-quality issues.
3. Standardized names, emails, and city names.
4. Normalized email addresses to lowercase.
5. Validated email formats.
6. Cleaned and validated phone numbers.
7. Handled missing and invalid ages.
8. Filled missing city values.
9. Removed duplicate customers using email addresses.
10. Validated the final dataset.
11. Exported cleaned customer records to CSV.

## Project Files
- `customer_data.csv` — Original sample dataset.
- `customer_cleaning.ipynb` — Notebook containing the cleaning process.
- `cleaned_customers.csv` — Cleaned customer dataset.

## Key Learning Outcomes
Practiced text normalization, missing-value handling, duplicate detection, email and phone validation, data-quality checks, and CSV export using Pandas.

## How to Run
1. Install Python.
2. Install dependencies using `python -m pip install pandas jupyter`.
3. Open the notebook in VS Code.
4. Select the Python kernel.
5. Run the notebook cells in order.

## Note
This project uses synthetic customer data. Email, phone, and age validation rules are simplified for learning purposes.
