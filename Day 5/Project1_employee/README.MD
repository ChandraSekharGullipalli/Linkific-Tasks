# Project 1: Employee Data Cleaning using Pandas

## Objective
Clean an employee dataset containing missing values, duplicate records, inconsistent text, and invalid age values.

## Tools Used
- Python
- Pandas
- Jupyter Notebook
- VS Code

## Tasks Performed
1. Loaded employee data from a CSV file.
2. Inspected the dataset and identified data-quality issues.
3. Removed extra spaces and standardized text.
4. Identified invalid age values and treated them as missing.
5. Handled missing age, salary, and city values.
6. Removed duplicate records.
7. Validated the cleaned dataset.
8. Exported the result to a new CSV file.

## Files
- `employee_data.csv`: Original sample dataset.
- `employee_cleaning.ipynb`: Data cleaning notebook.
- `cleaned_employees.csv`: Cleaned output dataset.

## Outcome
Practiced essential Pandas data-cleaning techniques to improve data quality and prepare structured employee data for further analysis.

## How to Run
Install Pandas using `python -m pip install pandas jupyter`, open the notebook in VS Code, select the Python kernel, and run each cell.

## Note
This is a learning project using synthetic employee data.
