# Project 2: Sales Data Cleaning using Pandas

## Objective
Clean and validate a sales dataset using Python and Pandas.

## Tools Used
- Python
- Pandas
- Jupyter Notebook
- Visual Studio Code

## Data Cleaning Tasks
1. Loaded sales records from a CSV file.
2. Inspected the dataset and identified data-quality issues.
3. Removed unnecessary spaces from text columns.
4. Standardized product names, categories, and regions.
5. Converted numeric and date columns to appropriate data types.
6. Removed duplicate transaction IDs.
7. Handled missing values.
8. Removed invalid quantities and unit prices.
9. Excluded records with invalid sale dates.
10. Calculated total sales for each transaction.
11. Validated the cleaned data.
12. Exported the cleaned dataset to CSV.

## Project Files
- `sales_data.csv` — Original sample sales dataset.
- `sales_cleaning.ipynb` — Notebook containing the cleaning process.
- `cleaned_sales.csv` — Cleaned output dataset.

## Key Learning Outcomes
Practiced data cleaning, type conversion, duplicate detection, missing-value handling, validation, and calculated columns using Pandas.

## How to Run
1. Install Python.
2. Install dependencies using `python -m pip install pandas jupyter`.
3. Open the notebook in VS Code.
4. Select the Python kernel.
5. Run the cells in order.

## Note
This project uses synthetic sales data for learning and practice.
